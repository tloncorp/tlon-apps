# Code Review Guidelines

The review rules live in the `## Code Review Rules` sections of `AGENTS.md`:
the root file for the whole repository, and the `AGENTS.md` in each area
(`desk/`, `packages/api/`, `packages/shared/`, `packages/app/`,
`apps/tlon-web/`, `packages/openclaw/`, `packages/hermes-tlon-adapter/`) for
the changed paths. `CLAUDE.md` files are symlinks to them. Apply the root
rules and those of every area the diff touches, including their "Do not flag"
lists.
