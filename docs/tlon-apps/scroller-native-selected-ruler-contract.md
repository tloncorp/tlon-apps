# Native selected-entry measurement roles

Declared before the focused controls and the next actual recording. This corrects a measurement-subject mismatch; it does not change renderer landing behavior or widen the accepted1pt tolerance.

The optional contract `ruler: 'indexed-cell-and-surfaces-v1'` measures the actual indexed ScrollerItem cell, the independently tagged inner message, and the actual composer/action/latest surfaces in one native operation. Outer metadata comes from ScrollerItem's resolved live post, and inner metadata comes from the actual message renderer. Missing, duplicate, wrong-scope, malformed or mismatched role evidence is incomplete. Old recordings retain their original ruler and original result; absence of the new marker cannot qualify the new contract.

Selected entry centers the measured indexed cell in the declared reserved reading region: the intersection of the measured native scroll clip and its bounds after actual adjusted content insets. Insets define reservation and legal offsets; they are not claimed to be an independently measured visible glass edge. Native top/bottom inset is applied exactly once. Latest/delayed still target the reachable legal end with actual message exposure.

The actual inner message must be inside its matching measured cell, have the same live semantic revision, and remain exposed. Its visible intersection with the reserved reading region must not be covered by any actually exposed primary composer, action or latest-control surface. Record partial overlays as individual rectangles. A48pt floating control must not turn a transparent full-width wrapper into an obstruction. No +8pt separator or +56pt control-clearance offset is inferred from source or silently applied to measurements.

Opt-in markers use existing production views and add no layout wrappers or scroll actions. A manifest on the actual composer chrome row declares the exact surfaces rendered in that scope; the same native walk inventories all tagged cells and surfaces. Keep both inventories bounded and fail closed on incomplete/duplicate inventory. The primary composer body is required. This initial ruler handles the existing normal composer surfaces; unobserved popup/foreign overlay and native presentation are not claimed.

Acceptance controls: preserve a healthy cell-center placement when the inner message excludes a separator; a transparent wrapper/control reservation changing alone must not shift the reading region; reject a measured cell displacement beyond1pt, covered inner message, missing/duplicate/unlisted surface, wrong scope/revision, inner frame outside cell, forged valid metadata, and missing new ruler. Actual primary composer inset growth changes the reserved region once. Preserve valid geometry failure even when unrelated role evidence is incomplete. Existing acquisition, ownership, action, deadline and1s tail requirements remain unchanged.
