# Coherent native scroll geometry evidence

This acceptance contract is recorded before implementation and tests. It augments the existing situation matrix without changing the accepted scroll policies or tolerances.

The capture observes the real iOS `UIScrollView` and mounted React Native row/composer views. A single dormant Expo `AsyncFunction`, dispatched to the main queue, reads their model geometry in one synchronous operation. It never forces layout, scrolls, changes an inset, or installs a timer. Ordinary conversations do not call it.

| Situation | Required evidence and acceptance |
| --- | --- |
| Static list, drag, momentum, keyboard or composer transition | Offset, content size, raw and adjusted insets, scroll bounds, viewport and row/composer window frames come from the same main-thread operation. No cached JS scroll event or LegendList estimate supplies geometry. Existing 1-point position criteria remain separate. |
| Multiple mounted conversations or replaced views | Find exactly one attached fixture root, one requested tagged scroll host and one outer native scroll view in that host. Each requested row must be uniquely identified in the root and belong to that scroll view. Composer must belong to the same root and window. Persist opaque native object identities. Ambiguous, missing required or wrong-owner views make capture incomplete. |
| Virtualized row detaches during the bridge round trip | Missing optional mounted rows are reported individually; required reading/mutation witnesses remain mandatory. A populated list with no measured rows is incomplete. JS scope, list membership and required ref identities must remain coherent around acquisition. No missing measurement becomes a zero-height row. |
| Oversized request or tree | At most 128 unique row identifiers and a bounded traversal of 20,000 views. Reject an over-limit or duplicate request; do not silently truncate it. A traversal limit reports incomplete capture. |
| Legal scroll range | Derive minimum and maximum from the same actual native content size, viewport bounds and `adjustedContentInset`. Preserve raw `contentInset` alongside adjusted values for diagnosis. Do not manufacture an extent from estimated list state. |
| Composer overlaps the list | Persist the actual native composer frame and clip the usable list bottom only when horizontal overlap exists. An absent, hidden, transparent or invalid composer/list witness is incomplete. The covered keyboard region is inferred from the measured composer/list overlap; it is not an independently measured keyboard frame. |
| Slow bridge or acquisition | Persist native monotonic start/end and JS request/receipt times with their separate clock domains. Enforce both native operation and complete JS bracket at most 32 ms. Assign the JS sample timestamp to receipt and report the entire bracket as timing uncertainty. Never pretend native and JS clock origins coincide. |
| Animation or presentation | Model-layer geometry is structural evidence only. It does not prove which frame was painted, animation smoothness, hidden overlay correctness, input latency or device frame pacing. Native presentation remains incomplete. |
| Old or unavailable native module | Preserve historical snapshots as legacy mixed-source data. The upgraded iOS fixture emits invalid acquisition with an explicit unavailable reason; it does not silently fall back and claim coherent native evidence. |

The reusable adapter validates raw capture identity, numerical values, view membership, timing and complete required witnesses independently of the desired scrolling outcome. Its controls must accept healthy capture and reject injected duplicate IDs, stale/mismatched request identity, wrong-parent rows, invalid bounds, missing composer or rows, oversized requests, native/JS clock errors, slow capture and over-limit traversal. Geometry outcome oracles continue to decide hold, landing and follow behavior.

Implementation files: `apps/tlon-mobile/modules/tlon-scroll-edge-effect/ios/ScrollEdgeElementContainer.swift` adds the method registration and bounded capture enum in the already registered source file, avoiding unnecessary CocoaPods project regeneration; `packages/app/fixtures/scrollNativeGeometry.ts` and `.test.ts` define the pure adapter and controls; `ScrollStability.fixture.tsx` calls it only on iOS. The optional diagnostics attach argument in `PostList/diagnostics.ts` and `PostList.tsx` supplies the actual generated scroll identifier. `scrollStabilityTrace.ts` only extends acquisition metadata. Fixture root and composer IDs are fixture-only. No native build or measured scenario will run until the parent freezes source.


Serialized replay preserves mathematical coordinate equality: JSON's conversion of negative zero to zero is permitted for legal scroll bounds. Every nonzero bound remains an exact comparison; invalid/nonfinite native values, mismatched identities, missing samples and timing limits remain unchanged. Controls must exercise a full JSON serialization round trip, a nonzero inset with a tiny corrupted bound, and a real geometry violation surviving the round trip. This narrow serialization correction does not upgrade incomplete capture intervals.
