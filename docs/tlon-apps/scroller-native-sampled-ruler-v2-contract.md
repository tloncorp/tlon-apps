# Native sampled ruler v2

This opt-in acquisition contract applies to ordinary iOS fixture captures with one mounted owner. Entry/reset/navigation captures retain the existing entry itinerary and v1 behavior. It is sampled native model geometry; presentation and between-sample motion remain unqualified. Historical artifacts and results are unchanged.

Before baseline acquisition and action, declare `nativeSampledRulerContract` with version `indexed-cell-and-surfaces-v2`, exact scope, rootId, scrollViewId and composerId. Every bracket and request must match. The independent reader establishes actual root/window/scroll/host/composer identities only from the first valid reproduced native acquisition; a later replacement or observed ABA makes the capture incomplete. Legitimate row/cell replacements remain allowed when each native walk proves the exact ancestry and semantic identity.

The same native walk supplies indexed cells, actual inner message frames, applied insets and a complete manifest of actual input/latest-control surfaces. Applied insets determine the usable viewport; a floating latest control does not turn the full composer wrapper into full-width occlusion. Required-row clipping and surface overlap remain checked in both dimensions. V2 separates ancestry from legitimate unclipped child overflow; no numeric containment or landing tolerance changes. Inner content remains the reading measurement, and indexed-cell geometry is separately retained.

Native semantic signatures require string content/reactions and finite nonnegative integer replies, matching the native fixture emitter. Matching empty objects do not establish a revision. The broader generic mutation type and historical v1 validation remain unchanged.

The independent importer regenerates and exactly compares all derived ruler fields—including surfaces, obstruction, cells, scope and latest visibility—from raw native capture. Deleted or forged fields cannot reach a product pass. Required anchor/tail/target obstruction fails valid sampled positional checks; missing, overlong or changed-owner acquisition remains incomplete and is never dropped. Latest-control visibility is a separate recorded UI fact; this acquisition contract does not certify its threshold, fade or flicker policy.

Ordinary witness-selection setup uses the same geometry but cannot certify the later capture. Android/web and absent/default adapter contracts remain unchanged. V2 does not change native sampling cadence, fix existing content movement, qualify entry concealment, or adopt any cancellation proposal.

Focused suite acceptance, declared before execution: `runSuite(id, names = automatedScenarios)` and `suite=core&scenarios=<comma-separated names>` preserve the exact requested order. Empty, duplicate, unknown or malformed selections reject before executing any case; a scenarios parameter requires suite=core. Omission retains all 38 automatic cases. Each selected case still resets through the existing path and retains its own raw trace. The suite report includes selectedScenarios for exact-count/order validation.

Validation: adapter/positional controls, default/v1 regression controls, actual independent-importer corruption controls, coherent row/cell replacement, and focused fixture selection controls. Native execution of this revision is pending; unit controls do not qualify a device result.

Latest visibility threshold metadata is declared before each ordinary capture using React Native Dimensions.get(window).height and multiplier 1. Record before/after values and observed height-change events through native stop. A changed height, including observed change-and-return, invalidates this fixed-window capture. No list/root-height substitution is permitted. This is threshold evidence, not native presentation proof.

## Buffered stationary continuity, before implementation

R17 retains two 18 pt near-remove observations between bridged samples, and R15
retains a 52 pt thinking gap that its bridged samples miss. The buffered native
recording must therefore be an independent required continuity gate for the
stationary append, prepend, thinking, image-load and non-anchor mutation cases.
Reuse the existing native recording acquisition and indexed ruler readers;
do not add a sampler or infer presented frames from display-link callbacks.

Check every buffered observation and the full recorded lifetime. FOLLOW must
remain within the existing 1 pt tolerance of the actual measured legal end.
HOLD must retain the declared unchanged anchor's viewport-relative position
within 1 pt. Require its actual exposed row/cell association, scope and physical
lifetime, unchanged membership incarnation, semantic signature and dimensions.
A changed anchor needs a different declared reading-point contract; it cannot
silently become a generic row-top proof. Partial-width obstruction counts.
No transient-clamp exception or baseline reset is introduced.

Acquisition gaps, malformed ownership, gestures, changed anchors and unsupported
scenario policies remain explicit incomplete or unassessed results. Do not drop
their frames or use a later valid state to restore qualification. Keep a valid
observed geometry failure distinct from missing mutation/action evidence, and
never promote either into presented-frame proof. A passing bridged result cannot
serve as a complete native continuity pass when the required buffer gate fails
or lacks qualification. Original frozen readers and raw results remain intact.

Controls must expose a transient jump followed by perfect recovery, including a
jump absent from bridged samples; reject corrupted identity, semantic, timing,
scope, exposure and gesture evidence; and retain stationary healthy controls.
The exact native R15/R17 recordings are replay evidence, not CI dependencies.
