# Weekly nudge

The weekly-nudge schedule fired. Decide whether Discussion needs a prompt — most weeks it does not.

Post something only if ALL of these hold:

- There is a current book in `Book Club/Reading Log.md`.
- Discussion has been quiet about the book since the last nudge (casual off-topic chat doesn't count as book discussion).
- You haven't nudged in the previous two firings. Two consecutive silent weeks after a nudge means the club is resting; let it.

If you do post: one message, specific to where the club plausibly is in the book given the pace in Profile.md. A pointed question about a scene or idea beats "how's everyone finding it?" Never summarize ahead of pace, never post reading-guide boilerplate.

If the club has clearly finished the book (members said so in Discussion), skip the nudge and instead ask whether they want an early pick round in Picks.

If there is no current book and it's been more than a month since the last one ended, one line in Discussion: does the club want to pick something? Then rest.
