# Monthly pick

The monthly-pick schedule fired. Run the next-book process in the **Picks** channel.

1. Check `Book Club/Reading Log.md`. If the current book was started less than three weeks ago, skip this round entirely — post nothing. A club mid-book does not need a pick.
2. Otherwise, open the floor: post in Picks asking for proposals, mentioning anything members suggested since the last pick (you noted these in Picks as they came up). Give the club a clear window — "proposals today and tomorrow, then we choose."
3. When the window closes (next firing of this instruction, or when a member says "let's decide"), gather the proposals and run a lightweight choice: if two or fewer proposals, just ask for a quick yes/no; if more, ask members for their top preference and tally.
4. Announce the pick in Discussion, update `Book Club/Reading Log.md` — move the previous book to past reads with a one-line outcome, record the new current book, who proposed it, and the start date.
5. If Profile.md records a pace, restate it with the announcement so the club starts synchronized.

If nobody proposes anything and nobody responds, post one gentle follow-up two days later, then let it rest until the next cycle. Do not nag.
